# Q-MAKER

تطبيق عربي محلي لإعداد الامتحانات ومراجعتها.

## التشغيل
افتح index.html أو استخدم GitHub Pages من فرع main والمجلد الجذري.

## الوظائف
- استيراد TXT وMarkdown أو لصق المنهج.
- تحويل PDF النصي وWord بصيغة DOCX إلى Markdown قابل للتحرير والتنزيل، أو استخدامه كمنهج.
- استخراج أسئلة من أسطر المصطلح: التعريف بقواعد محلية، وتحرير الأسئلة والإجابات.
- قوالب إعدادات JSON وحفظ واستيراد المشروع.
- طباعة PDF وتصدير HTML متوافق مع Word بامتداد DOC.

## التحويل
تعمل المعالجة داخل المتصفح، ولا تُرفع المستندات إلى خادم. تُحمّل PDF.js 4.10.38 وMammoth 1.8.0 وTurndown 7.2.0 عند الطلب من jsDelivr؛ يلزم اتصال إنترنت ومتصفح حديث. الحد 20 ميغابايت و300 صفحة PDF. يدعم DOCX ولا يدعم DOC القديم. لا يتوفر OCR للملفات المصورة. راجع ترتيب العربية والأعمدة والجداول؛ لا تُضمن مطابقة التصميم ولا الصور أو المعادلات. PDF يستخرج النص مع فواصل صفحات؛ DOCX يحافظ على العناوين والقوائم والتنسيقات النصية الأساسية والجداول البسيطة قدر الإمكان.

لا توجد خدمة توليد بالذكاء الاصطناعي أو حسابات أو مزامنة. راجع المحتوى قبل اعتماد الامتحان ونزّل نسخة احتياطية من المشروع. لا تضع مفاتيح API في الموقع العام.
