# Q-MAKER

تطبيق عربي محلي لإعداد الامتحانات من التعريفات ومراجعتها.

## التشغيل
افتح `index.html` في متصفح حديث، أو استضف الملفات عبر GitHub Pages. من Settings → Pages اختر Deploy from a branch ثم main و / (root).

## الوظائف
- استيراد TXT وMarkdown أو لصق المنهج.
- استخراج تعريفات وأكمل الفراغ واختيار من متعدد بقواعد محلية؛ يحتاج كل تعريف سطراً بصيغة المصطلح: التعريف.
- تحرير الأسئلة والإجابات وإضافة أسئلة يدوياً.
- قالب إعدادات JSON، وحفظ واستيراد المشروع، وحفظ تلقائي في المتصفح.
- طباعة الورقة أو مفتاح الإجابة إلى PDF عبر المتصفح.
- تصدير HTML متوافق مع Word بامتداد DOC، وليس DOCX أصلياً.

## حدود النسخة
لا توجد خدمة ذكاء اصطناعي أو قراءة تلقائية لملفات PDF وDOCX أو مطابقة شكل قالب Word. لا توجد حسابات أو مزامنة بين الأجهزة. يجب مراجعة المحتوى قبل استخدامه في امتحان. بيانات المشروع تبقى في المتصفح ويُنصح بتنزيل نسخة احتياطية. لا تضع أي مفاتيح API داخل ملفات الموقع العامة.
